# مقرأة الإمام الجزري — Frontend

واجهة ويب أولية لمنصة مقرأة الإمام الجزري للإقراء والإجازة بالسند.

## التقنيات

- Next.js
- React
- JavaScript
- CSS
- API backend منفصل

## اللغات

- العربية
- الأمهرية

تبقى المصطلحات المتخصصة في القراءات والإقراء والإجازة والسند
بالعربية داخل النصوص الأمهرية.

## المتطلبات

- Node.js بإصدار يدعم إصدار Next.js المحدد في package.json
- npm
- عنوان API صالح للخادم الخلفي

## إعداد المشروع

1. افتح مجلد frontend.
2. ثبّت الحزم:

   npm install

3. انسخ .env.example إلى .env.local.
4. ضع عنوان API الخلفي في متغير NEXT_PUBLIC_API_URL.
5. شغّل الواجهة:

   npm run dev

6. افتح العنوان الذي يظهر في الطرفية.

## صفحات الواجهة

- / : الصفحة الرئيسية
- /register : التسجيل
- /login : تسجيل الدخول
- /student : حساب الطالب
- /teacher : لوحة المعلم الأولية
- /admin : لوحة الإدارة الأولية

## ملاحظات التكامل

هذه الواجهة لا تستبدل الخادم الخلفي ولا قاعدة البيانات الحالية.

يجب مطابقة مسارات API وأسماء الحقول مع الخادم الفعلي قبل
اعتماد تسجيل المستخدمين أو المدفوعات أو خصم الدقائق.

لا تضع DATABASE_URL أو كلمات مرور قاعدة البيانات أو مفاتيح
الخادم السرية في ملفات الواجهة.

لا تسمح للواجهة وحدها بتحديد صلاحيات المستخدم أو اعتماد الدفع.
يجب التحقق من الهوية والصلاحيات في الخادم.

يجب تسجيل كل تغيير في الرصيد من خلال منطق الخادم وسجل الحركات
المعتمد، وعدم حذف الحركات المالية السابقة.

سعر الدقيقة المعتمد في قواعد المشروع هو 5 ETB.
لا تخصم دقائق بسبب الغياب أو إلغاء الجلسة.
لا تغيّر قاعدة البيانات الحالية أثناء إعداد الواجهة.
