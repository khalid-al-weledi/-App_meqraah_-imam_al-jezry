# App_meqraah_-imam_al-jezry
# مقرأة الإمام الجزري للإقراء والإجازة بالسند

منصة لإدارة تعليم القرآن الكريم والقراءات والإجازة بالسند.

## مكونات المشروع

- backend: الخادم وواجهة API.
- admin: الموقع ولوحة الإدارة.
- bot: بوت Telegram.
- mobile_app: تطبيق الهاتف.
- database: مخطط قاعدة البيانات الجديدة.

## البرامج الرئيسية

1. برنامج التلقين وتصحيح الأداء.
2. برنامج حفظ القرآن الكريم.
3. برنامج الإعداد لإجازة حفص عن عاصم.
4. برنامج القراءات السبع.

## القواعد المالية

- سعر دقيقة القراءة: 5 بر إثيوبي.
- لا تُضاف الدقائق إلا بعد اعتماد الدفع.
- رفع إيصال الدفع لا يعني اعتماد الدفع.
- لا تُخصم الدقائق عند الغياب أو إلغاء الجلسة.
- تُخصم الدقائق بعد اعتماد جلسة حضرها الطالب.
- تحفظ الحركات المالية في سجل قابل للمراجعة.

## اللغات

- العربية.
- الأمهرية.

تبقى المصطلحات القرآنية والعلمية مثل قراءة وسند وإجازة
وقراءات بالعربية داخل النصوص الأمهرية.

## الأمان

- استخدام قاعدة بيانات جديدة مستقلة.
- عدم تعديل قاعدة البيانات القديمة.
- عدم رفع الأسرار إلى GitHub.
- تطبيق صلاحيات على الخادم.
- اختبار العمليات المالية قبل التشغيل الفعلي.

## حالة المشروع

هذا المستودع قيد البناء والاختبار.
لا يُعد جاهزًا للإنتاج حتى تكتمل الوظائف المطلوبة
وتُختبر قاعدة البيانات والصلاحيات والعمليات المالية.
